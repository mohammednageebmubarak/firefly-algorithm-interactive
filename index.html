1. ما خوارزمية اليراعات؟

خوارزمية اليراعات (FA) هيخوارزمية تحسين تقريبية قائمة على مجموعة من الحلول، مستوحاة من الإشارات الضوئية التي تصدرها اليراعات. قدّمها Xin-She Yang عام 2008. تستخدم فكرة انجذاب اليراعات الأقل سطوعًا إلى اليراعات الأكثر سطوعًا، مع انخفاض الانجذاب كلما زادت المسافة.

اليراعة

حل مرشح، أي متجه قيم متغيرات القرار.

سطوع اليراعة

مقياس لجودة الحل المستنتجة من دالة الهدف.

الانجذاب

حركة نحو حل أفضل تتأثر بالمسافة.

العشوائية

استكشاف مناطق جديدة لا تكفي الحركة الحتمية لاكتشافها.

التمييز المهم: Firefly ليست بحد ذاتها نموذج تعلم آلي، بل أداة تحسين يمكن استخدامها لتطوير أو ضبط نماذج التعلم الآلي أو لاتخاذ قرارات تشغيلية أفضل.

مثال مدخلي

نريد تقليل دالة التكلفةf(x) = (x − 3)². الحل الأمثل المعروف هنا هوx = 3وتكلفته صفر. في المشكلات الكبيرة لا يكون الموقع الأمثل معروفًا مسبقًا، ولهذا نستخدم البحث التقريبي.

2. العناصر الرياضية الأساسية

دالة الهدف Objective Function

min f(X)   or   max f(X)

إذا كانت المشكلة تقليل تكلفة، فإن قيمة الدالة الأصغر تعني حلًا أفضل. وإذا كانت تعظيم منفعة فالعكس صحيح.

المسافة بين حلين

rᵢⱼ = √[ Σₖ (xᵢₖ − xⱼₖ)² ]

في مثال نقطتين A=(2,3)، B=(5,7)، تكون المسافة √(9+16)=5.

الانجذاب Attractiveness

β(r) = β₀ exp(−γ r²)

المعامل β₀ هو الانجذاب عند مسافة صفر، أما γ فيتحكم في سرعة انخفاض الانجذاب مع المسافة.

معادلة الحركة Movement

Xᵢ(t+1) = Xᵢ(t) + β₀e−γrᵢⱼ²(Xⱼ(t)−Xᵢ(t)) + αεᵢ(t)

تتكون من:الموقع الحالي + التحرك نحو حل أفضل + خطوة عشوائية. يحدد α شدة الاستكشاف العشوائي، وε متغيرًا عشوائيًا.

مثال يدوي محلول

A عند x=1 وتكلفتها 4، وB عند x=2 وتكلفتها 1. إذا كانت β₀=1 وγ=0.1 وα=0.2 وε=0.25:

r = 1;   β = e−0.1 ≈ 0.9048
xnew = 1 + 0.9048(2−1) + 0.2(0.25) ≈ 1.9548
f(1.9548) ≈ 1.0924

انخفضت تكلفة A من 4 إلى قرابة 1.0924، لكنها لم تتجاوز جودة B بعد؛ التكرار هو ما يسمح بمتابعة البحث.

5. خوارزمية Firefly بلغة Python

هذا تنفيذ مبسط قريب من النموذج الرياضي مع ضبط حدود المتغير، وحفظ أفضل حل مكتشف. لتشغيله في Python ثبّت NumPy أولًا بالأمرpip install numpy.

import numpy as np

def objective(x):
    return (x[0] - 3) ** 2

def firefly(n=20, iterations=100, alpha=0.2,
            beta0=1.0, gamma=0.1, seed=42):
    rng = np.random.default_rng(seed)
    positions = rng.uniform(0, 6, (n, 1))
    scores = np.array([objective(p) for p in positions])
    index = np.argmin(scores)
    best_x = positions[index].copy()
    best_score = scores[index]

    for _ in range(iterations):
        for i in range(n):
            for j in range(n):
                if scores[j] < scores[i]:
                    distance = np.linalg.norm(
                        positions[i] - positions[j]
                    )
                    beta = beta0 * np.exp(-gamma * distance**2)
                    noise = alpha * (rng.random(1) - 0.5)
                    candidate = positions[i] + beta * (
                        positions[j] - positions[i]
                    ) + noise
                    positions[i] = np.clip(candidate, 0, 6)
                    scores[i] = objective(positions[i])
                    if scores[i] < best_score:
                        best_score = scores[i]
                        best_x = positions[i].copy()
    return best_x, best_score

x, value = firefly()
print('x =', x[0], 'f(x) =', value)

6. تطبيقات في نظم المعلومات

حالة بحثية مقترحة

اختر 3 مراكز توزيع من 10 مواقع مرشحة. يمكن تمثيل اختيار الموقع k بمتغير ثنائي xₖ∈{0,1}، مع القيد Σxₖ=3. ويمكن أن تجمع دالة الهدف المطبّعة تكاليف النقل ومسافة الوصول وعدد غير المخدومين. ستحتاج خوارزمية اليراعات هنا إلى تكييف للقرارات المنفصلة أو دالة إصلاح للقيود.
