## العربية

منصة تعليمية تفاعلية مبسطة لفهم **خوارزمية اليراعات (Firefly Algorithm)**، موجهة لطلاب علوم الحاسوب ونظم المعلومات والباحثين المبتدئين في خوارزميات التحسين المستوحاة من الطبيعة.

### المميزات
- التبديل بين **العربية والإنجليزية** من داخل الصفحة، مع اتجاه قراءة مناسب لكل لغة.
- شرح دالة الهدف، والمسافة الإقليدية، وقوة الانجذاب، ومعادلة حركة اليراعات.
- أدوات تفاعلية لتجربة معاملات الخوارزمية، مع محاكاة تعليمية خطوة بخطوة.
- مثال رياضي محلول، وأمثلة من نظم المعلومات.
- اختبار ذاتي مع تصحيح فوري ومثال برمجي بلغة Python.
- ملف **index.html** مستقل، لا يحتاج إلى خادم أو حزم خارجية للتشغيل المحلي.

### التشغيل دون تنزيل من GitHub
افتح **[رابط الدرس المباشر](https://mohammednageebmubarak.github.io/firefly-algorithm-interactive/)**. هذه صفحة GitHub Pages وليست صفحة عرض الكود. في حالة عدم فتح الرابط، راجع **Settings → Pages** واختر **Deploy from a branch → master → / (root)**.

### التشغيل دون إنترنت
نزّل ملف **[index.html](./index.html)** مرة واحدة، ثم افتحه في أي متصفح حديث. تستطيع استخدام أدوات التفاعل محليًا دون اتصال بالإنترنت.

## English

An interactive bilingual learning resource introducing the **Firefly Algorithm (FA)** for computer science and information systems students and beginning optimization researchers.

### Features
- Switch between **Arabic and English**, including reading direction.
- Learn objective functions, Euclidean distance, attractiveness and the Firefly movement equation.
- Explore parameters and a step-by-step teaching simulation.
- Work through a mathematical example and information-systems use cases.
- Take a self-check quiz and explore a Python example.
- **Single-file HTML** that works locally without a build process.

### View online (no download)
Open the **[live learning website](https://mohammednageebmubarak.github.io/firefly-algorithm-interactive/)** in your browser. This uses GitHub Pages, not the GitHub source-code preview. If it is not yet accessible, configure **Settings → Pages → Deploy from a branch → master → / (root)**.

### Use offline
Download **[index.html](./index.html)** once, then open it in a modern browser. No network connection is needed for the built-in learning activities.
